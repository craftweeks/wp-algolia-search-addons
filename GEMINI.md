# Gemini Project Instructions

This document provides instructions for the Gemini AI assistant on how to work with the WP Algolia Search Addons project.

## Project Overview

The WP Algolia Search Addons project is a WordPress plugin that enhances the functionality of the WP Search with Algolia plugin. It provides features like excluding pages from indexing, Polylang integration for multilingual search, and WP-to-Static support for URL rewriting.

## Project Conventions

### Commit Messages

This project uses the GitMoji convention for commit messages. The format is `emoji type(scope): subject`.

Common emojis include:
- `✨ :sparkles: feat` (new features)
- `🐛 :bug: fix` (bug fixes)
- `📝 :memo: docs` (documentation)
- `🔧 :wrench: chore` (config files)
- `🔨 :hammer: chore` (dev scripts)
- `♻️ :recycle: refactor` (code refactoring)

For a full list, refer to [https://gitmoji.dev](https://gitmoji.dev).

### Coding Style

This project follows the WordPress coding standards for PHP, and a consistent style for JavaScript and CSS. Please adhere to the existing coding style when making changes.

## Development Environment

The development environment is a standard WordPress installation with the following plugins installed:
- WP Search with Algolia
- Polylang

## Testing

This project does not have a dedicated testing framework yet. Please perform manual testing to ensure that the changes are working as expected.

## AI Instructions

- **Analyze before you act**: Before making any changes, analyze the existing code, tests, and configuration to understand the project's conventions and patterns.
- **Mimic the style**: Follow the existing coding style, structure, and architectural patterns.
- **Ask for clarification**: If a request is ambiguous, ask for clarification before proceeding.
- **Explain your changes**: After making changes, provide a clear and concise summary of what you've done.
- **Keep the user informed**: Keep the user informed about your progress and any issues you encounter.
